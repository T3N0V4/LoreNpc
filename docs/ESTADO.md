# Estado de LoreNPC

## Objetivo
Sistema de NPC vanilla personalizables mediante comandos.

## Requisitos
- Crear NPC con ID y nombre.
- Mantenerlos inmóviles.
- Editar hasta tres preguntas y respuestas.
- Interactuar mediante clic derecho.
- Ocultar y recuperar NPC.
- Conservar datos entre reinicios.
- Agregar personalidades posteriormente.
